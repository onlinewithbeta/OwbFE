POST /signin
Authenticate and retrieve your API key and account details.
Request Body
Field Type Required Description
password string required Account password
identifier string required Email address or username
useGmail boolean required Set true to authenticate with Gmail
useUsername boolean required Set true to authenticate with username
Example Request
{
  "password": "your_password",
  "useGmail": true,
  "useUsername": false,
  "identifier": "user@example.com"
}
Responses
200
Success
{ "gmail": "...", "balance": 12500, "username": "john_doe", "key": "OWB_..." }
500
Server Error
{ "message": "Internal server error" }
curl -X POST https://api.onlinewithbeta.name.ng/signin \
  -H "Content-Type: application/json" \
  -d '{
    "password": "your_password",
    "useGmail": true,
    "useUsername": false,
    "identifier": "user@example.com"
  }'
const response = await fetch('https://api.onlinewithbeta.name.ng/signin', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    password: 'your_password',
    useGmail: true,
    useUsername: false,
    identifier: 'user@example.com'
  })
});
const data = await response.json();
console.log(data.key); // your API key

POST /data
Purchase a data plan for MTN, Airtel, or GLO. Requires API key.
Authorization Header
apikey: Bearer YOUR_API_KEY
Request Body
Field Type Required Description
network string required Network operator: mtn | airtel | glo
planId integer required Plan ID from GET /plans
phone string required 10-digit recipient phone number
Responses
201
Purchase Successful
{ "message": "Purchase successful", "balance": 5380 }
401
Unauthorized
{ "message": "Please create an account or login" }
401
Insufficient Funds
{ "message": "Insufficient balance. You need ₦500 more to complete this purchase." }
500
Server Error
{ "message": "Something went wrong" }

GET /fund
Retrieve your current wallet balance in naira (₦). Requires API key.
Authorization Header
apikey: Bearer YOUR_API_KEY
Response 200
12000
The response is a plain integer representing your current NGN wallet balance, not a JSON object. 
curl -X GET https://api.onlinewithbeta.name.ng/fund \
  -H "apikey: Bearer YOUR_API_KEY"
const response = await fetch('https://api.onlinewithbeta.name.ng/fund', {
  headers: { 'apikey': 'Bearer YOUR_API_KEY' }
});
const balance = await response.text();
console.log("Balance: ₦" + balance);
HttpRequest request = HttpRequest.newBuilder()
  .uri(URI.create("https://api.onlinewithbeta.name.ng/fund"))
  .header("apikey", "Bearer YOUR_API_KEY")
  .GET()
  .build();

HttpClient.newHttpClient()
  .sendAsync(request, HttpResponse.BodyHandlers.ofString())
  .thenApply(HttpResponse::body)
  .thenAccept(b -> System.out.println("Balance: ₦" + b));
$ch = curl_init("https://api.onlinewithbeta.name.ng/fund");
